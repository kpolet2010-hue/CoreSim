# Examples

There are no example programs yet. The CPU cannot execute instructions so far, and no opcodes have a meaning.

What can be tried today:

- `src/main.cpp` decodes a sample instruction and prints its fields (see [DECODER.md](../docs/DECODER.md)).
- The test suites in `tests/` show how each component is used (see [TESTING.md](../docs/TESTING.md)).
